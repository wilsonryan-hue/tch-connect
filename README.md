## Deploy

`.github/workflows/pages.yml` publishes the repo root to GitHub Pages on every push to `main`.

One-time setup (repo admin): **Settings > Pages > Build and deployment > Source: GitHub Actions**. The workflow cannot enable Pages itself because the default `GITHUB_TOKEN` is not allowed to create a Pages site.
